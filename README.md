# Plugins AD5X

Отдельные пользовательские плагины и интеграции для Flashforge AD5X с Z-Mod.

Цель репозитория — хранить кастомизации вне рабочих деревьев Z-Mod, Klipper, Moonraker и других upstream-компонентов, чтобы штатные обновления не блокировались локальными изменениями.

Первая задача: [ZMOD-CLEAN-CUSTOMIZATIONS-001](https://github.com/genrudko/Plugins_AD5X/issues/1).
